# QGate

**QGate** — *an easy gateway to Qualcomm Device Cloud (QDC).*

QGate is a lightweight command-line tool that simplifies connecting to QDC systems by automatically handling SSH tunneling, port forwarding, and launching RDP sessions.  
It provides a faster, cleaner way for engineers to access remote QDC devices securely.

---

## 🚀 Goal
To provide an intuitive and efficient interface for connecting and managing QDC sessions — reducing manual setup and enabling rapid access for developers, testers, and automation systems.
